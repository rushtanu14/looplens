# LoopLens demonstration

Use a clean browser session and actual app interactions. Target 90–120 seconds. Burn English captions and retain subtitle/transcript files. The media README records the actual final timing.

1. **Problem:** A wrong total is not enough to explain a loop bug. Introduce the predict, trace, compare workflow.
2. **Predict:** Use the default loop from zero while `i < 5`; enter prediction `15`. Explain that the prediction is recorded before the result appears.
3. **Trace:** Reveal two rows slowly, then finish. Hold the result at `10` and show that the visited values are 0, 1, 2, 3 and 4.
4. **Compare:** Compare the default inclusive alternative. Hold the first difference at iteration 6: the original has stopped while the alternative includes 5 and reaches 15.
5. **Keep evidence:** Export the Markdown receipt. It contains configurations, prediction and trace rows, not merely a screenshot.
6. **Guard a mistake:** Select the countdown challenge and run it. Explain that adding 1 moves away from zero. Finish the preview and show the incomplete label, then compare the decrementing alternative.
7. **Limit:** This is a browser-local simulator for simple integer loops. It does not execute arbitrary source or prove learning gains. Every preview is capped at 200 iterations.

Use synthetic example values only. No external account actions occur during recording. Any chapter/caption overlays belong to the recorder, not application source.
